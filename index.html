Jornada do Usuário e Service Blueprint

Disciplina: Interação Humano-Computador (IHC)

```
```

Introdução

Em projetos de Interação Humano-Computador (IHC), compreender como os usuários interagem com sistemas é fundamental para criar experiências eficientes, intuitivas e satisfatórias.

Duas técnicas amplamente utilizadas para esse propósito são a Jornada do Usuário (User Journey) e o Service Blueprint.

```
```

O que é Jornada do Usuário?

A Jornada do Usuário representa todas as etapas percorridas por uma pessoa ao tentar alcançar um objetivo utilizando um produto, sistema ou serviço.

Ela permite identificar ações, expectativas, emoções, dificuldades e oportunidades de melhoria ao longo da experiência.

Objetivo: compreender a experiência do usuário sob sua própria perspectiva.

Elementos da Jornada

  • Ações realizadas pelo usuário.
  • Pontos de contato com o sistema.
  • Objetivos e necessidades.
  • Sentimentos e percepções.
  • Problemas encontrados.
  • Oportunidades de melhoria.
```
```

Exemplo Prático

Compra de ingresso de cinema online

1. Descoberta

O usuário decide assistir a um filme.

2. Pesquisa

Busca horários e cinemas disponíveis.

3. Compra

Seleciona assentos e realiza o pagamento.

4. Utilização

Recebe o ingresso e vai ao cinema.

```
```

O que é Service Blueprint?

O Service Blueprint é uma representação detalhada de um serviço que mostra não apenas o que o usuário vê, mas também todos os processos internos necessários para entregar essa experiência.

Diferença principal: enquanto a Jornada do Usuário mostra a experiência percebida, o Service Blueprint revela também os bastidores do serviço.
```
```

Estrutura do Service Blueprint

  • Evidências físicas: elementos visíveis ao usuário.
  • Ações do usuário: atividades realizadas pelo cliente.
  • Frontstage: interações visíveis.
  • Backstage: atividades internas.
  • Processos de suporte: sistemas e infraestrutura.
```
```

Exemplo de Service Blueprint

Aplicativo de entrega de refeições

Usuário Escolhe refeição Realiza pagamento Acompanha entrega
Frontstage Exibe cardápio Confirma pagamento Mostra rastreamento
Backstage Recebe pedido Processa transação Aciona entregador
Suporte Banco de dados Gateway de pagamento Sistema de geolocalização
```
```

Exemplo da Vida Real

Agendamento de Consulta Médica

O paciente pesquisa uma clínica, escolhe um profissional, agenda a consulta e recebe a confirmação.

Internamente, o sistema verifica disponibilidade, registra os dados, atualiza agendas e envia notificações.

Comparação

Foco na experiência do usuário. Foco na experiência e nos processos internos.
Mostra ações e emoções. Mostra ações, pessoas e sistemas.
Visão externa. Visão externa e interna.
Mais simples. Mais detalhado.
```
```

Aplicação em IHC

  • Compreender o comportamento dos usuários.
  • Identificar problemas de usabilidade.
  • Projetar experiências mais eficientes.
  • Melhorar serviços digitais.
  • Apoiar o desenvolvimento centrado no usuário.
```
```

Conclusão

A Jornada do Usuário e o Service Blueprint são ferramentas complementares. Enquanto a primeira ajuda a compreender a experiência do usuário, a segunda permite visualizar toda a estrutura necessária para entregar essa experiência.

Em IHC, ambas contribuem para o desenvolvimento de sistemas mais eficientes, acessíveis e alinhados às necessidades dos usuários.
