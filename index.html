Jornada do Usuário e Service Blueprint

Interação Humano-Computador (IHC)

Introdução

Em IHC, compreender como o usuário interage com sistemas digitais é essencial para projetar boas experiências.

Este material utiliza o exemplo de um aplicativo de delivery de comida para explicar os conceitos de forma prática.

Jornada do Usuário

A Jornada do Usuário representa o caminho percorrido por uma pessoa ao utilizar um sistema.

Exemplo prático: Usuário quer pedir comida em um aplicativo.

Descoberta

Usuário sente fome e decide pedir comida.

Pesquisa

Abre aplicativos como iFood ou Uber Eats e compara opções.

Decisão

Escolhe um restaurante com melhor avaliação e preço.

Compra

Seleciona itens e realiza o pagamento no app.

Uso

Acompanha a entrega até receber o pedido.

Service Blueprint

O Service Blueprint mostra o que acontece por trás da experiência do usuário.

Mesmo cenário: aplicativo de delivery de comida.

Usuário

Abre app e escolhe restaurante
Seleciona prato e paga
Aguarda entrega
Interaction Line

Frontstage (o que o usuário vê)

Interface mostra restaurantes
Confirma pedido e pagamento
Exibe status da entrega
Line of Visibility

Backstage (bastidores)

Restaurante recebe pedido
Sistema processa pagamento
Entregador é acionado

Suporte (sistemas)

Banco de dados registra pedido
API de pagamento valida transação
Sistema de GPS rastreia entrega

Comparação

A Jornada do Usuário foca na experiência percebida. O Service Blueprint mostra também os processos internos.

Conclusão

O uso conjunto dessas técnicas permite entender tanto o comportamento do usuário quanto a estrutura necessária para entregar a experiência.
